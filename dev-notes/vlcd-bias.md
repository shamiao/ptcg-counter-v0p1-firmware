# VLCD 偏压方案

## 拓扑

P1.1 输出 **50kHz** PWM（PWMA CH1 PWM1N，6MHz/120 计数，ARR=119），经 **1.8kΩ + 1µF** RC 滤波（τ=1.8ms，纹波 ~10mV）得到直流 VLCD。

实测要点：

- **PWM1N 引脚占空比（高）= CCR1/(ARR+1)**：PWM1N 在此输出非反相 OC1REF。
- **负载电流**（HT1621 偏压分压网络 + 点亮面板）两组反推：早期 R=10kΩ 时 3.3V 天花板 2952mV 法得 ≈35µA（等效 ~85kΩ）；拆改验收时按表读反推 ≈80µA（压降 ≈148mV）。反推是"大数相减"，手持表 1–2 字分辨力内两值并存；固件常数 `VLCD_IR_DROP_MV=63` 保持未改，实测 VLCD 落在 3.13–3.15V，显示良好。
- **对滤波电容有效容值天然钝感**：直流输出表达式里没有 C，C 只影响纹波（即使 Y5V 最坏 0.3µF，纹波也仅 ~27mV）。唯一值得保证的是介质不是 Y5V（建议 0805 1µF 50V X7R）。

## 控制律（开机一次性施加）

直流模型：`VLCD = VCC × CCR/120 − 63mV`。上电 ADC15 自测 VCC 一次后：

| VCC | 策略 |
|-----|------|
| ≤ 4.3V | 关 PWM，P1.1 推挽输出 1（放任：VLCD = VCC − 63mV，最高 ~4.24V，用户确认面板承受得住） |
| 4.3V ~ 5.5V | `CCR = 120 × (3200+63)mV / VCC`（四舍五入；4.3V→76%、4.5V→72%、5.4V→60%），**占空比硬下限 60%（CCR≥72）**，VLCD ≈ 3.2V |
| ADC 读数失败 | 走 60% 占空比下限（安全侧失效，3.3V 轨下 VLCD ~1.9V 屏不亮但无害） |
| ≥ 5.5V（仅开机检查） | 打印故障信息后进入公共致命函数 `SleepForever()`：VLCD 硬拉低、全部 IO 恢复准双向安全态（HT1621 总线空闲）、全中断关闭、MCU 永久掉电（PCON PD）+ 死循环兜底，拒绝执行一切后续代码 |

**2026-09-28 修订（用户决定）**：PWM 启用门限从 3.263V（"够得着 3.2V"）提高到 **3.6V**。调节目标仍 3.2V 不变；3.2~3.6V 之间是刻意留宽的死区——引脚保持纯 GPIO 高而不是在近满占空比 PWM/GPIO 两态间切换，避免调节点附近的模式抖动造成显示闪烁；代价是死区内 VLCD 超调至最高 ~3.54V，用户确认面板可承受。

**2026-09-28 二次修订（用户决定）**：PWM 启用门限 3.6V → **4.3V**，为适应 **LIR2032 充电电池**（3.6V 标称、充电上限 ~4.2V）——锂电池整个放电区间都落在死区内，引脚全程保持纯 GPIO 高，不会随电池电压在 PWM/GPIO 两态间切换。死区内 VLCD 最高 ~4.24V（VCC=4.3V 时），用户确认面板承受得住。调节目标 3.2V、60% 占空比下限、5.5V 过压门禁均不变。

`SleepForever()` 是所有自检失败的公共出口。VCC 与占空比只在开机时处理一次，正式版的连续调节方案另行设计。

## 验收数据（2026-09-28，R=1.8k + 1µF 定型）

| VCC | VLCD 实测 |
|-----|-----------|
| 3.27V | 3.13V |
| 4.98V | 3.13V |

VCC 变化 ±23% 而 VLCD 恒定，线性稳压达标。注意 3.27V 点实际是 **VCC 天花板**（占空比顶满 100%，等价推挽直高），4.98V 点（CCR=79）才是真稳压；两机制恰落同一电压，边界行为无缝。

## 历史注

- 最初按 datasheet 风格假设 VLCD ≈ 1.3V 直流，台架否定（面板根本不亮）。
- 1Ω 直驱 + PWM 斩波阶段得出经验律 `VLCD读数 = VCC×√占空比`（3.3V 下 90% 最佳）——该律描述斩波直驱，改 RC 滤波后作废。
- 18.2kHz/1Ω/1µF 组合曾把 GPIO 输出拖塌：1µF 在 18.2kHz 下容抗 ≈8.8Ω，经 1Ω 几乎直接并在推挽输出上，满摆幅需 ~160mA 平均无功电流，输出塌成 ~1.8V 有效值、LCD 黑屏。勿再复现。
